# Shan Tech Alliance (STA)
## Shan Language Artificial Intelligence (Shan AI)
ၶူင်းၵၢၼ်ႁူမ်ႈသၢင်ႈ ႁႅင်းသဵင်ပၢႆးၸၢင်ႊ AI ၽႃႇသႃႇတႆး                                                                      
ၶူင်းၵၢၼ်တႃႇတေၶူင်ႊသၢင်ႈဢွၵ်ႇ ၸုမ်ႇၶေႃႈမုၼ်းႁႅင်းသဵင်ပၢႆးၸၢင်ႊ AI ၽႃႇသႃႇၵႂၢမ်းလၢတ်ႈတႆး၊  တႃႇယုၵ်ႉယွင်ႈၵၢၼ်ၸႂ်ႉတိုဝ်း ပၢႆးၸၢင်ႊ( ပၢႆးထႅၵ်ႇၼေႃႇလေႃႇၵျီႇ) လႄႈၵၢၼ်ၶဝ်ႈထိုင်ၶေႃႈမုၼ်း ၼႂ်းတူင်ႇဝူင်းၽႃႇသႃႇၵႂၢမ်းလၢတ်ႈတႆး၊ တွၼ်ႈတႃႇႁႂ်ႈပီႈၼွင်ႉတႆး ၵူႈပၢၼ်ၵူႈသႅၼ်း ၸႂ်ႉတိုဝ်းၻိတ်ႉၵျိတ်ႉတၼ်လ် လႄႈ AI လႆႈငၢႆႈငၢႆႈလူၺ်ႈၽႃႇသႃႇတူဝ်ၵဝ်ႇ။     
### 📌 ယိူင်းဢၢၼ်းၶူင်းၵၢၼ် (Objectives)
* ၶူင်ႊသၢင်ႈလႄႈ ပိုၼ်ၽႄပၼ် ပၢႆးၸၢင်ႊ AI တႃႇၽႃႇသႃႇၵႂၢမ်းလၢတ်ႈတႆး။ (Tai/Shan Language)
* ၶူင်ႊသၢင်ႈ ၶိူင်ႈၸႂ်ႉတိုဝ်း ၶေႃႈမုၼ်းပိုတ်ႇတိုၼ်း (Open Source) တႃႇႁႂ်ႈၽူႈၶူင်ႊသၢင်ႈတၢင်ႇၸိူဝ်း ဢဝ်ၵႂႃႇ ၸႂ်ႉတိုဝ်းသိုပ်ႇႁုၼ်ႈမုၼ်းလႆႈ။
* ပိုၼ်ၽႄပၼ်တၢင်းႁူႉ ၶၢဝ်ႇငၢဝ်း လႄႈ ပွင်ႈၵႂၢမ်းပၢႆးၸၢင်ႊ လူၺ်ႈၿလွၵ်ႉ (Blog) ၼႆႉ။
